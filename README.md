# KneeGrow

> Smart Rehabilitation. Intelligent Recovery.

KneeGrow is an AI-assisted smart knee rehabilitation system that monitors range of motion, tracks recovery progress, and provides real-time haptic feedback to improve physical therapy outcomes. By combining wearable sensors with edge computing, KneeGrow delivers continuous rehabilitation insights both inside and outside clinical environments.

## Overview

Traditional knee rehabilitation relies on periodic clinical assessments and manual monitoring, making it difficult to track patient progress consistently. KneeGrow bridges this gap with a wearable rehabilitation platform that captures motion data in real time, analyzes joint movement, and provides immediate feedback to encourage correct exercise execution.

## Features

- Real-time knee angle monitoring
- Range of Motion (ROM) tracking
- Wearable sensor integration
- Haptic feedback for corrective movement
- Live rehabilitation dashboard
- Recovery progress analytics
- Edge computing with Raspberry Pi

## Tech Stack

- Raspberry Pi
- ESP32
- MPU6050 IMU
- Flex Sensor
- ADS1115 ADC
- Python
- FreeRTOS
- Mobile Dashboard

## Vision

Build an intelligent rehabilitation platform that enables affordable, accessible, and data-driven physical therapy through wearable technology and edge AI.
